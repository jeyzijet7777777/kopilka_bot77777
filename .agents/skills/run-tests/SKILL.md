# Запуск тестов в Kopilka Bot

Перед сдачей любого изменения обязательно запускайте тест-сьют:

```bash
pytest -v
```

Тесты проверяют:
- Целостность SQLite базы и маркера томов (`test_datasafe.py`)
- Корректность миграций схемы (`test_migrations.py`)
- Генерацию месячных отчетов и графиков (`test_month_report.py`)
- Логику копилки и банка сдачи (`test_step2_features.py`)
- Сериализацию состояний (`test_bot_storage.py`)
